# Effets sonores téléchargés (Pixabay)

Dépose ici des effets sonores téléchargés sur https://pixabay.com/sound-effects/ (licence Pixabay :
usage commercial autorisé, sans mention obligatoire). Nomme chaque fichier selon son rôle ; il remplace
alors automatiquement l'effet synthétisé du même nom dans toutes les vidéos.

| fichier | rôle | idée de recherche Pixabay |
| --- | --- | --- |
| `whoosh_in.mp3` | ouverture de la vidéo | whoosh intro |
| `whoosh.mp3` | changement de plan | swoosh transition |
| `stamp.mp3` | révélation (« FAUX ») | stamp impact |
| `thump.mp3` | coup sourd, opposition | deep hit / boom |
| `plinks.mp3` | gouttes d'eau | water drop |
| `tick.mp3` | apparition d'un élément | ui tick / soft click |
| `click.mp3` | appui sur le bouton « abonne-toi » | button click |
| `warn.mp3` | mise en garde | alert / warning beep |
| `check.mp3` | élément validé | success ding |
| `shimmer.mp3` | arrivée du logo | magic sparkle / shimmer |
| `pop.mp3` | bulle, bouton « partage » | pop |

Formats acceptés : mp3, wav, ogg, m4a. Garde des sons courts (moins de 2 s).
La règle absolue s'applique toujours : chaque effet est filtré hors de la bande de la voix, et il est
baissé ou supprimé automatiquement s'il gêne un mot.
